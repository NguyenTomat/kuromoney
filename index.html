Cách 1: Thêm ra màn hình chính (Dùng Ngay Không Cần Cài)

1. Mở link app trên trình duyệt Safari của iPhone.
2. Bấm nút Chia sẻ (Share) ở thanh dưới cùng Safari.
3. Chọn "Thêm vào MH chính" (Add to Home Screen).
4. App sẽ hiển thị icon Kuromi full màn hình không viền như app tải từ App Store!

Cách 2: Build Xcode / File IPA qua Capacitor (1 Dòng Lệnh)

Dự án đã chuẩn bị sẵn cấu trúc tương thích 100% với Capacitor:
npm install @capacitor/core @capacitor/cli @capacitor/ios
npx cap init KuroMoney com.kuromoney.app
npx cap add ios && npx cap open ios
Chạy trên Xcode là bạn có ngay app iOS native mượt mà!
